Hallazgos — Diagrama de clases: Invernadero automatizado (AMS)
Equipo: ______________________

1. Relación Lectura — Sensor (herencia)
   Tipo: Herencia mal usada · Contradice: R2
   lectura no es una herencia ya que no tiene algo que ver con un sensor

2. Relación Sector — Invernadero (composición)
   Tipo: Multiplicidad incorrecta · Contradice: R1
   en cada sector hay un solo invernadero,como las bombas de riego

3. Relación Sector — Sensor (asociación «tiene»)
   Tipo: Multiplicidad incorrecta · Contradice: R2
   cada sector tiene entre 1 o mas sensores,no solamente 1

4. Encargado · - telefono: String
   Tipo: Otro · Contradice: Regla de modelado
   telefono no seria de dato string, tiene que ser de tipo int.

5. SensorHumedad · - profundidad: int
   Tipo: Vocabulario inconsistente · Contradice: Regla de modelado
   no seria profundidad, seria humedad

6. Clase Alerta
   Tipo: Relación faltante · Contradice: R5
   la alerta no se esta relacionando con el sistema

7. SensorTemperatura · - unidad: String
   Tipo: Atributo en la clase equivocada · Contradice: Regla de modelado
   no muestra bien el nombre del atributo y ademas aunque lo tuviera el tipo de dato deberia ser int
